How to Use the Ratio Calculator

Enter any 3 known numbers into the boxes to solve equivalent ratios (A : B = C : D). The missing value automatically calculates using cross-multiplication.

Ratio Formula

The cross-multiplication formula used to solve missing values is:

A × D = B × C

Common Uses for Ratios

  • Screen Resolutions: Calculate 16:9 aspect ratios for videos.
  • Recipe Scaling: Scale cooking ingredients up or down.
  • Scale Models: Calculate real dimensions from maps or blueprints.
